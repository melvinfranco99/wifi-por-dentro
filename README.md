# Wifi por dentro

Web explicativa (con gráficas interactivas) sobre cómo funciona el wifi con varios puntos de acceso:
señal y distancia, canales e interferencias, señal y velocidad (SNR/MCS), roaming y cliente pegajoso,
minimum RSSI y 802.11v, potencia y tamaño de celda, y analizadores wifi.

**Web:** https://melvinfranco99.github.io/wifi-por-dentro/

Todos los números salen del mismo modelo que los programas del laboratorio
(pérdida = 40 + 30·log10(d) + 5 por pared, ruido -95 dBm, wifi 4 con 2 antenas).
HTML, CSS y JavaScript sin dependencias.
